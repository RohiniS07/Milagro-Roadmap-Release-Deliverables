How to Add a New Roadmap

📁
Create a subfolder → upload index.html → update portal card
Each roadmap lives in its own folder. Add the HTML as index.html and it gets its own clean URL instantly.
Milagro-Roadmap-Release-Deliverables/
├── index.html                    ← this portal ✅
├── smartpos/e2e/index.html        ← E2E roadmap ✅ Draft
├── smartpos/jetcompose/index.html  ← add when ready
├── milagro-cloud/index.html        ← add when ready
├── delivery-tracker/index.html     ← built from TSV
└── backlog/index.html             ← built from TSV
